# Gap State
*How the buyer stands toward their own Gap right now -- Felt, Outcome, Unseen, or Denied.*

## Executive summary

Every buyer you meet already has a relationship with their own Gap: the distance between their Current State and their Desired Outcome. Some feel it hurting today, some are building toward a goal, some feel nothing, and some are sure there is nothing to feel. Gap State names those four positions -- Felt Gap, Outcome Gap, Unseen Gap, Denied Gap -- so you can read the buyer and engage the way they are ready to be engaged, instead of running the same play on everyone.

## Bottom line

Read the buyer's Gap State before you decide how to engage: move with a Felt Gap, build on an Outcome Gap, seed an Unseen Gap, and never argue with a Denied Gap.
