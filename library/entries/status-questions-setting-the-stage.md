# Status Questions - Setting the Stage
*Practical teaching for sellers and sales leaders on status questions - setting the stage.*

## Executive summary

Status questions set the stage for the sales process. These questions help sellers discover data and information about a buyer's current status in order to identify their needs. While data questions have value, sellers must avoid asking too many of these questions and focus on information questions to discover a buyer's needs, and what is required to close the gap between their current status and ideal solution. Status Questions: Setting the Stage As sellers focus on information questions rather than data questions, they will have a more engaging, informative conversation with their buyers and uncover their true needs.

## Bottom line

Status questions set the stage for the sales process.
