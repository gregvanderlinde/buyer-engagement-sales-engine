# term:gap-state -- Gap State

**Bottom line:** how the buyer stands toward their own Gap right now -- Felt, Outcome, Unseen, or Denied -- read from their words, never assumed.

**In here:**
- Felt Gap / Outcome Gap / Unseen Gap / Denied Gap
- It is the buyer's direction in their own business, not toward you
- Read in the Curiosity Conversation; write it on the Buyer Profile
- Full Entry: library/entries/gap-state.md

## Body

Felt Gap: escaping a problem now -- move with them. Outcome Gap: building toward a goal -- build on it. Unseen Gap: content -- seed and wait. Denied Gap: sure nothing is wrong -- light touch or walk. Read it per person and re-read it every Conversation.
