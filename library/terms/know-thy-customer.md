# term:know-thy-customer -- Know Thy Customer (Role / JD / Focus)

**Bottom line:** learn the buyer's ROLE from their job description and current focus, then feed it into the Buyer Profile and Power Map.

**In here:**
- Living Role Card (JD + measured_on + current_focus)
- JD + Focus intake (pull / mine / free-find; [FOUND]/[CONFIRM])
- How it feeds Fit Six + Power Map
- Update never overwrite

## Why

A title alone ("VP Sales") tells you nothing to sell to. The role's job description tells you what that seat owns and is measured on; the role's current focus tells you what is top of mind THIS quarter. Selling to the mandate + the current focus is what makes outreach land. Focus changes, so this must be updatable.

## Role Card store

Workspace home: `work/roles/<RoleTitle>.md` (e.g. `work/roles/VP_Sales.md`). Company-specific branches allowed (`VP_Sales__Acme.md`). Free role worksheet front: `library/worksheets/role-jd-read.md`. Full Run Role Card template is paid-only (not in this Free zip). Worksheet pointer: `library/worksheets/role-jd-read.md`.

## Intake

- Seller-side seed: Discovery seeds Role Cards for ICP ideal buying roles.
- Per-pursuit RESEARCH: open/create Role Card; pull JD; mine seller sources; free-find archetype; capture current_focus; tag [FOUND]/[CONFIRM]; never invent.
- Later pursuits: update existing card -- refresh focus, append update_log; never overwrite history.

## Feeds the pursuit

- job_description + measured_on -> Fit Six Desired Outcome and Priorities
- typical_pains + current_focus -> Fit Six Roadblocks and Current State
- edge_angle -> ties seller Edge to this seat
- Each Power Map seat links its Role Card

## Ethics

Public / provided sources only; tag [CONFIRM] on inference; never fabricate a person's focus. Understanding the role, not profiling the private individual.
