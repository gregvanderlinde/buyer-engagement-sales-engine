# Project Priority Assessment
Rank sales projects and initiatives before you start them.

## Bottom line
Helps sales leaders decide which projects to launch by scoring initiatives on strategic, revenue, and feasibility criteria.

## When to use
- A backlog of sales initiatives exceeds capacity.
- Leadership wants a ranked project list tied to goals.
- You need to kill or defer low-impact busywork.

## What it covers
Sheets: Overview, Instructions, Project Priority, Project Scoring, Rankings. Criteria examples: alignment with goals, market positioning, seller capabilities, revenue potential, money available, long-term benefit, existing skills, technology, people. Importance weights total 100%. Projects scored 1-6; Rankings return weighted order.

## How to run it (seller)
1. Set importance on Project Priority (100% total).
2. Edit project names on Project Scoring; score 1-6.
3. Read Rankings for weighted priority.
