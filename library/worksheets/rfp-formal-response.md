# RFP Formal Response
Respond when you helped shape the RFP: thank stakeholders, map goals, add differentiators.

## Bottom line
Formal RFP cover/response outline for primed opportunities: introduction, stakeholder goals, key differentiators outside the original RFP, feedback close, and Cc strategy.

## When to use
- You were involved in priming or shaping RFP requirements.
- Stakeholder interviews uncovered goals not yet listed in the RFP.
- You need a buyer-focused response letter, not a feature dump.

## What it covers
NOTE from source: do not use this path if you arrived late -- use RFP Late Response instead. Must: address key stakeholders; Cc appropriate buyers; response-time timeline; up-to-date services description; appreciation. Sections: Introduction; Goals (primary goals from interviews highlighted in the RFP); Key Differentiators (capabilities executives wanted beyond original scope); Opportunity for Feedback; Cc guidance. Follow the buyer's required RFP format for the full package.

## How to run it (seller)
1. Confirm you primed the RFP; otherwise switch to Late Response.
2. List goals from stakeholder interviews and mark which appear in the RFP.
3. Add only validated differentiators executives requested.
4. Cc the stakeholder whose requirements align most with your offer.
