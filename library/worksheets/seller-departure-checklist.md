# Seller Departure Checklist
Protect accounts, access, and property when a seller leaves.

## Bottom line
Manager/HR/IT checklist covering notifications, equipment, exit interview topics, territory handoff, personal items, call forwarding, and file transfer.

## When to use
- A seller resigns or is terminated.
- Accounts, CRM access, and devices must be secured on a set date/time.
- You need a clean handoff script for inbound calls.

## What it covers
Manager: notify HR with docs; notify facilities/IT for access cutoff (especially at termination meeting time); notify Finance/Payroll; list equipment and account files to return; review territory (top accounts, stakeholders, transition plan, pending opportunities/RFPs, at-risk accounts); return personal print/computer files; clear personal items; forward email/phone; create admin messaging. HR: exit interview when employee-initiated (compensation, benefits, confidentiality, property return, forwarding info, project status, document locations). IT: transfer work files to a secure review location. Sample admin scripts for routing callers to the new owner.

## How to run it (seller)
1. Walk the checklist in order; mark Activity Complete/Comments on each step.
2. Coordinate access cutoff timing with the termination or last-day plan.
3. Complete territory and stakeholder handoff before the seller is gone.
4. Pair messaging with the New Account Manager Introduction Script.
