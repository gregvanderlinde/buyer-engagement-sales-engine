# Internet Acceptable Use Policy
Set appropriate and prohibited internet use for sellers (browsers, messaging, uploads/downloads, voice), with security, monitoring/filtering, and compliance consequences.

## Bottom line
Account setup by role, encouraged business uses, banned illegal/personal excess uses, password security, monitoring/filtering options, disclaimer, and signed agreement with indemnity language -- finalize with HR/IT/legal.

## When to use
- Granting sellers internet access for research, webinars, client work, and approved learning.
- Aligning sales-needed sites/tools with IT support and filtering choices.
- Collecting signed acceptable-use acknowledgments before access.

## What it covers
Purpose (email, IM, browsers, file transfer, voice); account and password control; management defines access by role and informs IT; encouraged uses (internal/client communication, research, approved education); inappropriate use (illegal activity, policy violations, mass mail, non-employee access, personal downloads, porn/gaming/entertainment/competitive commercial use unless pre-approved, unauthorized data destruction, large personal attachments); security (no password sharing, reset if compromised); failure to comply (remove access, discipline/termination, legal action); monitoring and optional filtering; disclaimer; acknowledgment with indemnity hold-harmless language and signature blocks.
