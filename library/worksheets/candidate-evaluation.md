# Candidate Evaluation
Compare seller candidates on the same weighted scorecard before you hire.

## Bottom line
Helps sales leaders systematically score and rank hiring candidates so the best fit for the role rises to the top.

## When to use
- Multiple finalists are in play for a seller role.
- You want hiring criteria tied to sales skills, experience, and interpersonal fit.
- Leaders need a defendable ranking after interviews.

## What it covers
Sheets: Overview, Instructions, Candidate Prioritization, Scoring, Rankings. Criteria cover Sales Perspective (sales skills, previous performance, direct industry experience), Experience Perspective (prior sales experience, formal sales training, academic background), and Personality Perspective (aptitude results, communication, interpersonal skills). Weights total 100%. Candidates are listed and scored 1-6 per criterion; Rankings return weighted order.

## How to run it (seller)
1. Copy the workbook; set role title and edit criteria/weights.
2. List each candidate on Scoring.
3. Score 1-6 per criterion via dropdowns where present.
4. Use Rankings for the ordered shortlist.
