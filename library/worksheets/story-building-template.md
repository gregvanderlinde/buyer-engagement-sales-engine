# Story Building Template
Build a short business story that creates engagement and transitions back to dialogue.

## Bottom line
Template for Context, Obstacle, Current Status, Requirements, Assistance Provided, and Outcome -- with numbers, value, and a clean transition.

## When to use
- You need credibility without a long value-prop dump.
- Pre-call planning calls for a relevant peer story.
- You want a trail-close question after the story (e.g. do you see how value was added).

## What it covers
Must include: relevant context; conversational tone (not a script reading); who/what/when/how details; numbers; value/benefits realized; transition back to buyer dialogue; appropriate tone. Template blocks: Context (industry/title, economy, company status/goals); Obstacle; Current Status; Requirements (status to goal in buyer words); Assistance Provided (unique capabilities); Outcome (accurate, relevant facts).

## How to run it (seller)
1. Pick a true peer story that matches this buyer's situation.
2. Fill each block; keep it short and conversational.
3. Include real numbers; never invent results.
4. End with a transition question back to the buyer's goals.
