# Sales Department Key Areas Assessment
Baseline the sales department across key performance areas before you change it.

## Bottom line
Helps sales leaders score the current state of the sales department from multiple perspectives so improvement work targets real gaps.

## When to use
- Annual planning or a new sales leader's first 90 days.
- Before funding a large sales transformation project.
- You need a shared picture of strengths and urgent issues.

## What it covers
Sheets: Overview, Instructions, Key Areas Assessment, Results. Category importance totals 100%; questions scored 1-6; comments for concerns. Results graph strengths and focus areas and flag very low scores as issues needing attention.

## How to run it (seller)
1. Set category importance to 100%.
2. Score each question 1-6; note concerns.
3. Review Results for strengths, focus areas, and urgent issues.
