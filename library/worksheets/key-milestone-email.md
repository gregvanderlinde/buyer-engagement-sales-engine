# Key Milestone Email
Tell stakeholders a milestone is done, check satisfaction, and preview the next date.

## Bottom line
Email structure for large/complex evaluations: milestone update, need-satisfaction check, next steps, feedback ask, appreciation -- buyer-results focused, not product pitch.

## When to use
- A project or evaluation milestone just completed.
- Senior stakeholders need concise progress without a product pitch.
- You want to prevent disconnect or buyer remorse from silence.

## What it covers
Must include: up-to-date key milestones; satisfaction inquiry; timeline for next milestone; appreciation; addressed to key stakeholder; appropriate Cc. Must not lead with seller product features -- focus on buyer results. Sections: Introduction; Need Satisfaction; Next Steps; Opportunity for Feedback / close.

## How to run it (seller)
1. Address the key stakeholder; Cc the right people.
2. State the milestone and date in one or two opening sentences.
3. Ask a short satisfaction question; state the next milestone and week.
4. Invite questions and thank them for continued support.
