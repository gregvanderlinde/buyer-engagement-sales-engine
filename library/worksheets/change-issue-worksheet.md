# Change Issue Worksheet
Plan how the buyer's team will absorb change so implementation does not stall the deal.

## Bottom line
Helps you map buyer change issues (time, resources, skill), name the owner, and announce support so the buyer's team buys into the transition.

## When to use
- A win depends on the buyer's people adopting a new process or system.
- You need internal support inside the buying organization beyond the champion.
- Implementation risk is creating late pushback.

## What it covers
Sections: Buyer Responsible for Implementation (name, role, primary responsibilities and staff); Buyer Issue examples (time / conflicting priorities, resources, skill gaps); Announce the Change (reason/purpose, training and coaching with name/when/explanation); multi-issue sample rows pairing each Issue with Explain support (Name, When, Explanation). Purpose: address buyer issues and serve as an administrative aid during implementation.

## How to run it (seller)
1. Name the buyer owner for implementation and their staff.
2. List each change issue (time, resources, skill, or other) in plain language.
3. For each issue, document the support you will provide: who, when, and what.
4. Share the announce-the-change narrative with the buyer's team before go-live.
5. Original remains a fillable template; this card is the library guide only.
