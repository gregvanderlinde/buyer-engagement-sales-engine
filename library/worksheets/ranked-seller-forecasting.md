# Ranked Seller Forecasting
Forecast from A/B/C seller mix -- not a flat headcount assumption.

## Bottom line
Helps sales leaders build a Buyer Engagement Forecast style outlook using historical sales by seller performance level (A/B/C) and planned headcount mix.

## When to use
- Building the next 12-month sales outlook.
- Modeling what happens if you add or lose A-level sellers.
- Growth scenarios need seller-mix reality, not average productivity only.

## What it covers
Sheets: Overview, Instructions, Ranked Seller Forecasting (historical input), Forecasted Sales, Growth Forecasting. Enter start month/year; historical months with total sales and counts of A/B/C sellers plus sales by level; optional percent weighting by level. Forecast tab: planned A/B/C headcount for future months; linear forecast fills from history. Growth Forecasting applies a growth percent what-if on top of the mix. Note in source: new sellers should be added only after productive ramp; tool does not model ramp-up time.

## How to run it (seller)
1. Copy the workbook; enter historical months and A/B/C counts and sales.
2. Set forecast headcount by level for coming months.
3. Optionally set growth percent on Growth Forecasting.
4. Read forecast tables/graphs; treat as decision support, not a guarantee.
