# RFP Late Response
Arrive late to an RFP? Ask for stakeholder access before you spend the bid team.

## Bottom line
Late-entry letter that states the late policy, requests stakeholder meetings, shares relevant value proof, and attaches a company overview -- give only if the buyer gives access.

## When to use
- The RFP arrived after others were already engaged.
- You need to test whether the buyer will give stakeholder time.
- You want to avoid becoming the third quote for legal cover.

## What it covers
Must: up-to-date evaluation plan; request to speak with stakeholders on business and personal needs; buyer-benefit description of offerings; addressed to key stakeholder; appropriate Cc. Sections: Introduction; Late Entry Policy Statement; Request to Meet (name stakeholders when known); Differentiation Statements and value proof; Closing with overview attached.

## How to run it (seller)
1. State you are late and that stakeholder conversations are required before a full response.
2. Ask for meetings with named stakeholders when possible.
3. Include only relevant peer results; attach a short company overview.
4. If access is refused, reconsider bidding (pair with Bid or No-Bid Assessment).
