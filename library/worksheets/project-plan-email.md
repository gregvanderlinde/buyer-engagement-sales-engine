# Project Plan Email
Cover letter that recaps concerns, transition support, and the attached project plan.

## Bottom line
For large/complex accounts: confirm buyer concerns and support needs, attach the plan, set a follow-up date -- results-focused, not a product pitch.

## When to use
- You are sending an implementation plan to the buyer's project lead.
- Concerns and transition support must be confirmed in writing.
- You need a formal cover email before next-step commitment.

## What it covers
Must include: confirmation of reasons/support already identified; suggested contact date/time for next steps; appreciation; up-to-date project plan; addressed to key stakeholder; appropriate Cc. Must not lead with seller product pitch. Sections: Introduction; Recap of Identified Key Concerns; Recap of Identified Transition Support Required; Confirmation (including tentative plan attached and follow-up date); Closing. Sample skeleton included in source.

## How to run it (seller)
1. Recap concerns and support items in the buyer's words.
2. Attach the current project plan; state who signs off.
3. Name the date you will call to discuss questions and next steps.
4. Keep the tone on buyer outcomes, not feature lists.
