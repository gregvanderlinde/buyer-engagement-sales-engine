# Differentiation Worksheet
When a buyer leans competitor, craft questions that change evaluation criteria in your favor.

## Bottom line
Structures Who (title, industry), an emotional concern question, a differentiator question, and an ideal-solution statement so the buyer re-evaluates criteria.

## When to use
- The buyer is leaning toward a competitor.
- You need plausible, tangible questions strong enough to change criteria.
- You want a short prep sheet before a competitive meeting.

## What it covers
Blocks: Who (title, industry); Emotional Question (e.g. How would you feel if...); Differentiator Question (e.g. Would you be interested in learning if there was a way...); Ideal Solution Statement that addresses the concern created. Questions must be plausible, tangible, and powerful enough to change criteria.

## How to run it (seller)
1. Identify the competitive pressure and the buyer title/industry.
2. Write one emotional concern question tied to a real delivery risk.
3. Write one differentiator question that points to your unique capability.
4. Draft the ideal-solution statement; test that it is fact-based.
