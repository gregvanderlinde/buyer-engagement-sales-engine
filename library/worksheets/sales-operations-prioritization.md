# Sales Operations Prioritization
Rank sales operations projects by where money, time, and effort should go.

## Bottom line
Helps sales leaders prioritize ops and process projects so scarce resources go to work that improves selling performance.

## When to use
- Sales ops backlog exceeds capacity.
- Sponsoring process or tooling projects for the sales team.
- You want impact-ranked options before funding.

## What it covers
Sheets: Overview, Instructions, Sales Prioritization, Project Scoring, Results. Evaluation criteria weighted; projects/initiatives listed and scored 1-6; Results/Rankings return weighted order. Source guidance: analyze existing seller, department, and company performance before starting a project.

## How to run it (seller)
1. Weight criteria on Sales Prioritization.
2. Edit projects on Project Scoring; score 1-6.
3. Read Results for weighted priority.
