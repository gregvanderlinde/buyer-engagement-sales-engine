# Value Proposition Worksheet for Prospecting
Craft a short, fact-based prospecting value proposition that earns a next conversation.

## Bottom line
Build industry- and title-specific value props from documented facts, numbers, and time frames -- buyer benefits first, not product features.

## When to use
- You have roughly 30-60 seconds to earn attention when prospecting.
- You need more than one value prop keyed to unique capabilities.
- Complex sales need higher specificity than transactional ones.

## What it covers
Must include: documented facts and assumptions; numbers ($, %, FTE, etc.); time frames; only relevant buyer benefits; clear transition to the buyer's status. Must not focus on company/product first -- focus on benefits seen in similar situations. Sections: Introduction; Applicable Benefits Seen; How you will help the buyer's company (from pre-call research); transition to ask for time.

## How to run it (seller)
1. Document the facts and assumptions behind each claim.
2. Write 2-3 sentences of intro, then quantified peer benefits, then a buyer-specific help statement.
3. Create multiple variants keyed to strengths and competitive differentiators.
4. Practice to time; drop anything that is not buyer-relevant.
