# Implementation Project Plan
Share a simple week-by-week milestone plan so seller and buyer own the work.

## Bottom line
A lightweight table of Week Of, Milestone, Responsible (seller / buyer), and Complete to keep deliverables from falling through the cracks.

## When to use
- You need a high-level plan stakeholders can scan.
- Seller and buyer must split ownership of milestones.
- Implementation or late-stage sales work needs a shared timeline.

## What it covers
Table columns: Week Of; Milestone; Responsible (seller and buyer); Complete. Use during the sales process and/or execution of project deliverables. Share as a high-level overview with all stakeholders involved.

## How to run it (seller)
1. List milestones by week with clear owners on seller and buyer sides.
2. Mark Complete only when both sides agree the milestone is done.
3. Distribute the overview to stakeholders; update after each checkpoint.
