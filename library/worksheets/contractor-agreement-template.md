# Contractor Agreement Template
Structure a clear contractor or consultant agreement for project work (generic HR/legal outline).

## Bottom line
Provides section-by-section guidance for work description, objectives, responsibilities, payment, schedule, change, confidentiality, IP, and termination -- not legal advice.

## When to use
- You are engaging a contractor for a defined project (training, web, specialist work).
- Leaders need a consistent outline before counsel drafts final language.
- Expectations on deliverables, payment, and IP must be explicit.

## What it covers
Sections described (content varies by company/project): Work Description; Objective(s); Contractor's Responsibilities; Company's Responsibilities; Performance requirements and fix process; Payment Information; Schedule; Change Process; Confidentiality; Non-Solicit and Non-Compete; Copyright / IP and indemnity; Governing Law; Force Majeure; Assignment; Contract Completion / Termination; signature blocks. Stay generic; have counsel finalize jurisdiction-specific language.

## How to run it (seller)
1. Fill each section with project-specific facts; leave blanks where legal must decide.
2. Define deliverables, milestones, payment triggers, and change signoff clearly.
3. Route to HR/legal before signature; this card is not a substitute for counsel.
4. Store the signed agreement per company policy.
