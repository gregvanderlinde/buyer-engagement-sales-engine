# Sales Tactics Leader Prioritization
Prioritize tactical sales options so leader energy follows impact.

## Bottom line
Helps sales leaders rank tactical options and projects that can improve results when resources are limited.

## When to use
- Many tactical ideas compete after a weak period.
- Choosing short-cycle plays versus longer projects.
- Aligning leaders on which tactics to run this quarter.

## What it covers
Sheets: Overview, Instructions, Sales Prioritization, Project Scoring, Rankings. Weight evaluation criteria; edit projects/initiatives; score 1-6; Rankings show weighted scores. Same family as other leader prioritization tools; use for tactical option ranking.

## How to run it (seller)
1. Weight criteria; list tactics/projects; score 1-6.
2. Read Rankings; run the top set and defer the rest.
