# Website Improvement Options Assessment
Rank website improvement options by sales impact and resource fit.

## Bottom line
Helps sales leaders prioritize website projects that support lead generation, branding, and selling when budget and time are limited.

## When to use
- Marketing asks sales for website priorities.
- Multiple site projects compete for the same sprint.
- You need a scored case for which site work helps sellers.

## What it covers
Sheets: Overview, Instructions, Improvement Prioritization, Scoring, Assessment. Edit improvement options; rate category importance to 100%; score 1-6; note concerns; check results/assessment for ranked outcomes.

## How to run it (seller)
1. List website improvement options; set weights to 100%.
2. Score 1-6; note concerns.
3. Use Assessment/Results for priority order.
