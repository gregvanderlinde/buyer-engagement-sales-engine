# Seller Communication Prioritization
Decide which messages and channels to sellers deserve priority.

## Bottom line
Helps leaders prioritize communication efforts to sellers so the most important messages get through without drowning the team.

## When to use
- Too many announcements compete for seller attention.
- Choosing channels or campaigns for a change rollout.
- Aligning sales enablement and leadership on message priority.

## What it covers
Sheets: Overview, Instructions, Communication Prioritization, Scoring, Rankings. Weighted criteria; list communication options; score 1-6; Rankings return ordered results. Same prioritization pattern as other Category 06 ranking tools.

## How to run it (seller)
1. Edit criteria and importance weights (100%).
2. List communication options; score 1-6.
3. Use Rankings to sequence what to send and when.
