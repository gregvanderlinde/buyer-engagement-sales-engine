# KPI Prioritization
Pick the few KPIs that will actually steer seller behavior.

## Bottom line
Helps sales leaders choose which KPIs to report and manage so the dashboard drives the right activities instead of noise.

## When to use
- Building or pruning a seller scorecard.
- CRM reports grew too long and behavior did not change.
- Aligning leaders on which metrics matter most this period.

## What it covers
Sheets: Overview, Instructions, Key Performance Indicators, Scoring, Rankings. You set importance of evaluation criteria, list KPI options on Scoring, score 1-6, and read weighted rankings. Purpose is decision support for which KPI reporting has the most impact across the team.

## How to run it (seller)
1. Copy the sheet; set criterion importance on the KPI tab.
2. Edit KPI options on Scoring to match your team.
3. Score 1-6; read Rankings for weighted priority.
